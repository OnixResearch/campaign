# Change-local acceptance

a[prepare-public-source.license] Current and new owned packages, code, contracts, schemas, fixtures, configuration, policy, lifecycle material, and documentation MUST be offered under `AGPL-3.0-or-later`. `LICENSE` MUST hold the complete GNU AGPL version 3 text. `NOTICE` MUST carry the copyright line `Copyright (c) 2026 OnixResearch`, the grant, and the AGPL no-warranty statement. The following MUST all name `AGPL-3.0-or-later`: the Cargo workspace license, the repository record, its pinned contract value, the exported projection, and the README License section. `provenance/SOURCE.md` MUST state that Campaign's own material is offered under `AGPL-3.0-or-later` per `NOTICE`, and that the owner grant changes neither that license nor the licenses of reused sources. A permanent configuration fixture that sets the historical `MIT OR Apache-2.0` value MUST fail with the pinned repository-license violation.

a[prepare-public-source.retained-terms] `LICENSE-MIT` and `LICENSE-APACHE` MUST stay byte-identical as historical grant texts. `NOTICE` MUST limit them to content they already cover and MUST NOT offer them for new contributions. `NOTICE` MUST identify three kinds of material as keeping their own terms: the pinned Choregraph dependency, the copied Cairn policy files with the terms Cairn offers for those bytes, and registry crates. `NOTICE` MUST NOT present the owner grant as extending to recipients. Every path outside the change's Impact list MUST stay byte-identical to the base revision. That includes Rust sources, lockfiles, Nix inputs, source inventory records, consumer records, and accepted specs. Within `Cargo.toml` and the repository-configuration files, only license lines MAY change.

a[prepare-public-source.public-checks] The README MUST list checks that pass under all of these conditions: the tree is exported outside the operator's home; `HOME` and the Cargo home are empty; global and system Git configuration are disabled; no SSH agent runs; no sibling checkout variable points at an operator checkout; and no dev shell is active. The README MUST name the tool sources for those checks, and the verification MUST use those sources. It MUST name, as explicit prerequisites, every private or SSH-only input in the locked closure of the complete gate, dev shell, and pre-commit hook. It MUST name the repository scripts that need private tools, including the aggregate `scripts/check.sh`. It MUST NOT claim that the complete gate passes for outside contributors.

a[prepare-public-source.references] Public documentation MUST NOT link to workspace-relative sibling paths, operator-local paths, or routes that refuse anonymous access. Git clone routes MUST appear as code, not hyperlinks. The README MUST name the canonical Radicle source and a public route observed to serve it. Sources without a public route MUST be named by identity and revision without a link. The README and `provenance/SOURCE.md` MUST NOT contain a full revision that no inventory entry records. Text-only sibling mentions in historical provenance records and the archived `final-gate.md` operator path are the only allowed exceptions.

a[prepare-public-source.handoff] The handoff evidence MUST name four things: the verified revision, every command and scan with its scope, the isolation conditions, and the observed results. It MUST report no unclassified gitleaks finding, and it MUST state the ref sets and commit counts that were scanned. It MUST list the publication effects that were not performed: GitHub repository creation, push, mirroring, visibility change, Radicle push or announcement, the workspace catalog URL, and the `git.onix.computer` route. Unexecuted or blocked checks MUST NOT be reported as passing.
